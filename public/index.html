Crypto Scalper

This repo is a Streamlit app. Vercel’s Python runtime only supports small ASGI/WSGI APIs—not a full Streamlit dashboard—so the live chart is not hosted here.

Run the dashboard online (recommended)

  1. Open Streamlit Community Cloud and sign in with GitHub.
  2. New app → pick this repository → main branch → main file: streamlit_app.py
  3. Deploy (uses requirements.txt automatically).

Note: Binance often blocks Streamlit Cloud’s US servers. If you see a region error, run the app on your PC or self-host outside the US; see the in-app help expander or .streamlit/secrets.toml.example.

Run on your PC

venv\Scripts\Activate.ps1
streamlit run streamlit_app.py
